01 · Features

One click. Whole flight deck.

EDLS does the boring part of every session: open Steam, start the game, start your tools, close them all afterwards.

Launch

Steam. Elite. Your tools. One key.

Press LAUNCH and EDLS starts Steam, boots Elite: Dangerous through min-ed-launcher, waits for the game, then brings up every companion tool you've ticked, in the order you set. Frontier's launcher never gets in the way.

  • Game already running? LAUNCH attaches to it instead of starting a second copy.
  • Tools you already had open are picked up, not restarted.
  • AUTO START launches the moment EDLS opens. One click becomes none.
Status

Every system at a glance.

A card for every app: Offline, Launching, Online. START or STOP any single tool from its card. The activity log records each step, PIDs included, and keeps a copy in launcher.log.

  • Cards follow tools you open or close yourself.
  • Drag the tool list in Settings to set the card order and the start order.

Teardown

Game closed. Tools closed.

When Elite exits, EDLS asks each tool to close, gives it three seconds, and only then forces the stragglers. Then it counts down five seconds and closes itself.

  • Changed your mind? LAUNCH turns into STAY OPEN during the countdown.
  • Close only what EDLS launched, or every enabled tool. Your call, in Settings.
  • SHUTDOWN does the same teardown on demand.
Loadout

Your tools. Your order.

Add any program, untick what you don't use, edit paths with %ENV% variables like %ProgramFiles%. On first run, only the tools EDLS finds on your PC start ticked.

  • Set your CMDR name for the header.
  • Optional: start tools minimized, so they stay out of the game's way.
Day mode

Full Daylight.

A light theme for bright rooms and washed-out monitors. The window around the status board lightens; the board itself stays a dark HUD. The toggle in Settings previews it live. This page has one too, top right.

Hands off

Never closes the game

EDLS never closes Steam or Elite: Dangerous. Force-closing the game breaks Frontier's terms. The Elite card has no STOP.

Admin

Elevation on request

EDLS never runs as administrator. A tool that asks for admin rights gets Windows' usual prompt, or you can turn that off.

Updates

A check and a badge

At startup EDLS asks GitHub for a newer release and shows a green UPDATE badge. It never downloads or installs anything itself.

Polite

Asks before it forces

Tools get a normal close request first. Only what's still running three seconds later is shut down.

03 · Setup

Preflight checks.

EDLS stands on two other projects. Set them up first, once, and confirm the game starts through them on its own.

  1. 01

    min-ed-launcher

    A minimal replacement for Frontier's launcher: the game just starts. Install it and follow its setup guide so Steam starts Elite through it.

    Setup guide
  2. 02

    Legendary

    A command-line Epic Games client. min-ed-launcher signs in through it, with an Epic account; that's what lets it skip Frontier's launcher. Install it, run legendary auth once, then point min-ed-launcher at it.

    Install Legendary
  3. 03

    EDLS

    Run the installer. On first run, tick your tools and check their paths. Once it works the way you like, turn on AUTO START.

    Download

NOTE Skip steps 1 and 2 and EDLS still starts your tools, but Frontier's launcher stays in the way, and you save very little time.

05 · FAQ

Comms log.

Will EDLS close my game?

No. EDLS never closes Steam or Elite: Dangerous: force-closing the game breaks Frontier's terms of service. Quit from the game's own menu. EDLS only closes your companion tools.

Why did Windows ask for admin rights?

Some tools (EDHM-UI, on most accounts) ask Windows for administrator rights. EDLS itself never runs as administrator, so when it starts one of these, Windows shows its usual UAC prompt. If EDLS has to close one later, Windows asks once more, one prompt for all of them.

Don't want the prompts? Turn off Ask for admin rights when a tool needs them in Settings, and EDLS leaves those tools to you.

My antivirus flagged it.

The installer is unsigned, and EDLS starts and closes other programs: some antivirus tools distrust that combination. Each release's notes link a VirusTotal analysis, and the source is all on GitHub.

Does it update itself?

No. From 1.3.0 on, EDLS asks GitHub for a newer release at startup and shows a green UPDATE badge next to your CMDR name. Click it for the steps and a link to the release page. Download the installer there and run it: it installs over your current version and keeps your settings. EDLS never downloads or runs an installer itself.

EDDI or VoiceAttack?

If you use EDDI through VoiceAttack's EDDI plugin, leave EDDI unticked and VoiceAttack ticked. The plugin starts EDDI and closes it with VoiceAttack. With both ticked, EDLS and the plugin can both try to start EDDI at once. Tick EDDI only if you run it on its own.

EDLS can't find one of my tools.

Open SETTINGS and set its path. Paths take environment variables, e.g. %ProgramFiles%. SrvSurvey's install path is hard to enter by hand: if EDLS can't find it, please report it on the issues page.

The game restarted and my tools closed.

A relog, or min-ed-launcher restarting the game, looks to EDLS like the end of the session. Press STAY OPEN during the countdown, then LAUNCH: EDLS attaches to the running game and starts your tools again.

Where are my settings and logs?

%LOCALAPPDATA%\EDLS\settings.json and %LOCALAPPDATA%\EDLS\launcher.log. Found a bug? Open an issue and attach launcher.log (Settings → OPEN LOG FOLDER), with your OS and hardware.
